**Quantum Computing with Qiskit**

This repository contains my quantum computing challenges and experiments using Qiskit.

**Challenge 1: Predict the Output**

Objective: To predict and investigate the measurement outcomes of single-qubit quantum circuits.

**Circuits**

Circuit A: One X gate — flips the qubit from 0 to 1.

Circuit B: Two X gates — returns the qubit to its initial state 0.

Circuit C: One Hadamard (H) gate — creates an equal superposition of 0 and 1.

**Tools Used**

-> Python

-> Qiskit

-> Qiskit Aer Simulator

-> Jupyter Notebook

**Results**

The circuits were simulated using 100 shots each. The measurement results and histograms are included in the notebook.
